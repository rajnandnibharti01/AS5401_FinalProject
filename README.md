# AS5401_FinalProject
Non-Intrusive Reduced-Order Modelling of a Diamond-Coated Si₃N₄ Sliding Contact under Lunar-Type Temperature and Load Variations: A Comparison of DMDc and Operator Inference.
Some information about the files attached
1. Files attached from Case01.npz to Case09.npz are extracted file from the ABAQUS/Standard which contains the data for the simulation run as mentioned in the paper.
2. ROM.py is the python file that loads the above mentioned Case01 to Case09 file to make rom_dataset.npz that contains the combined cases data and rom_test_metrices.csv that has testing cases of all the methods that are evaluated in this project.
3. Other .png files are the output of the ROM.py run
